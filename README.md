# Neon Stack React UI/UX Prototype

Fresh Vite + React frontend implementing the premium Neon Stack direction discussed in the design review.

Routes: `/`, `/collections`, `/category/:slug`, `/custom-neon`, `/about`, `/contact`.

Run:

```bash
npm install
npm run dev
```

This is a frontend prototype. Product content/pricing and imagery are placeholders. The Custom Neon Builder demonstrates text, fonts, colours, shapes, logo upload UI, room backgrounds, wall upload and responsive layout. Connect the existing WordPress/WooCommerce API in the next phase.
